# Deploy Gấu Bakery + AI CSKH lên Render (PHP + Python) với Aiven MySQL

Guide triển khai production stack:
- **Render Web Service #1** — PHP 8.2 Apache (site + widget + admin, đã có).
- **Render Web Service #2** — Python FastAPI (`ai-service`, cần tạo mới).
- **Aiven MySQL** — DB managed, kết nối SSL từ cả 2 service Render + MySQL Workbench local.
- **Facebook Messenger** — webhook dùng URL Render trực tiếp (không cần ngrok).

## 3. Sửa PHP để hỗ trợ SSL MySQL (Aiven yêu cầu)

Aiven bật `require_secure_transport=ON` — kết nối non-SSL bị reject. PHP native `mysqli_connect` cần config SSL context.

### 3.1 Commit CA cert vào repo

Đặt file `ca.pem` từ Aiven vào `config/aiven-ca.pem`. **Không secret** (public CA), commit được.

### 3.2 Sửa hàm connect DB

Tìm file connect DB (thường `config/database.php` hoặc `includes/db.php`):

```bash
grep -rn "mysqli_connect\|new mysqli\|new PDO" config includes --include="*.php"
```

Nếu dùng `mysqli`:
```php
$ssl = getenv('DB_SSL_CA');
$mysqli = mysqli_init();
if ($ssl && file_exists($ssl)) {
    mysqli_ssl_set($mysqli, null, null, $ssl, null, null);
    $flags = MYSQLI_CLIENT_SSL;
} else {
    $flags = 0;
}
mysqli_real_connect(
    $mysqli,
    getenv('DB_HOST'),
    getenv('DB_USER'),
    getenv('DB_PASS'),
    getenv('DB_NAME'),
    (int) (getenv('DB_PORT') ?: 3306),
    null,
    $flags
);
```

Nếu dùng PDO:
```php
$pdo = new PDO(
    "mysql:host={$host};port={$port};dbname={$db};charset=utf8mb4",
    $user, $pass,
    [PDO::MYSQL_ATTR_SSL_CA => __DIR__ . '/../config/aiven-ca.pem']
);
```

### 3.3 Add env var

Trong `render.yaml` block PHP `envVars` thêm:
```yaml
- key: DB_SSL_CA
  value: /var/www/html/config/aiven-ca.pem
```

## 4. Sửa ai-service (Python) để hỗ trợ SSL MySQL

### 4.1 Bổ sung config

Sửa `ai-service/app/config.py` thêm field:
```python
mysql_ssl_ca: str = ""      # empty = no SSL, else path to ca.pem
```

Sửa `ai-service/app/deps.py` chỗ tạo pymysql connection:
```python
def _conn_factory():
    kwargs = dict(
        host=settings.mysql_host,
        port=settings.mysql_port,
        user=settings.mysql_user,
        password=settings.mysql_password,
        database=settings.mysql_database,
        charset="utf8mb4",
        cursorclass=pymysql.cursors.DictCursor,
        autocommit=True,
    )
    if settings.mysql_ssl_ca:
        kwargs["ssl"] = {"ca": settings.mysql_ssl_ca}
    return pymysql.connect(**kwargs)
```

### 4.2 Commit CA cert vào ai-service

Copy `ca.pem` sang `ai-service/config/aiven-ca.pem`. Sửa `ai-service/Dockerfile`:
```dockerfile
COPY config ./config
```
Thêm sau dòng `COPY data ./data`.

Debug lỗi:
- **502 Bad Gateway** ai-service: check Render logs, thường Chroma init fail (disk) hoặc Gemini key sai.

## 9. Chạy eval offline (dataset 150 mẫu)

Chạy **local** với venv, kết nối Aiven MySQL — không chạy trên Render (tốn CPU quota, không cần production).

```powershell
cd ai-service
python -m venv venv
venv\Scripts\pip install -r requirements.txt

# .env local
copy .env.example .env
# Sửa .env:
#   GEMINI_API_KEY=...
#   MYSQL_HOST=gau-bakery-db-xxx.a.aivencloud.com
#   MYSQL_PORT=12345
#   MYSQL_USER=bakery_app
#   MYSQL_PASSWORD=...
#   MYSQL_SSL_CA=config/aiven-ca.pem
#   ENGINE=multiagent
#   ENABLE_NORMALIZER=true

# Build dataset 150 mẫu (xem eval/dataset/README.md)
venv\Scripts\python -m eval.generate_synthetic > eval\dataset\_synthetic_raw.jsonl
# Review manual → append vào samples.jsonl

# Validate
venv\Scripts\python -c "from eval.dataset_schema import load_dataset; print(len(load_dataset('eval/dataset/samples.jsonl')))"
# expect: 150

# Chạy 2 engine + ablation
venv\Scripts\python -m eval.run_eval --engine baseline   --out eval/results/baseline.jsonl   --sleep 4
venv\Scripts\python -m eval.run_eval --engine multiagent --out eval/results/multiagent.jsonl --sleep 4

$env:ENABLE_NORMALIZER = "false"
venv\Scripts\python -m eval.run_eval --engine multiagent --out eval/results/multiagent_no_norm.jsonl --sleep 4
Remove-Item Env:\ENABLE_NORMALIZER

# Phân tích M1-M6 + Wilcoxon
venv\Scripts\python -m eval.analyze `
  --baseline eval/results/baseline.jsonl `
  --multiagent eval/results/multiagent.jsonl `
  --dataset eval/dataset/samples.jsonl `
  --out eval/results/comparison.md
```

Commit results:
```bash
git add eval/results/
git commit -m "eval: baseline vs multiagent on 150-sample dataset"
```

## 10. Kết nối Workbench để admin DB production

Đã setup ở bước 2.1. Dùng để:
- Xem `chat_sessions`, `chat_messages` realtime khi test widget.
- Query stats: intent breakdown, handoff rate.
- Backup: **Server → Data Export** → schema `banh_store` → dump SQL.

Query hữu ích:
```sql
-- Sessions hôm nay
SELECT id, source, status, intent_label, updated_at
FROM chat_sessions
WHERE DATE(created_at) = CURDATE()
ORDER BY id DESC;

-- Handoff tickets đang open
SELECT t.id, t.subject, t.priority, s.source, m.content AS last_msg
FROM support_tickets t
JOIN chat_sessions s ON s.id = t.session_id
LEFT JOIN chat_messages m ON m.id = (
  SELECT MAX(id) FROM chat_messages WHERE session_id = s.id
)
WHERE t.status IN ('open','in_progress')
ORDER BY t.created_at DESC;

-- Intent distribution 7 ngày
SELECT intent_label, COUNT(*) c
FROM chat_sessions
WHERE created_at > NOW() - INTERVAL 7 DAY AND intent_label IS NOT NULL
GROUP BY intent_label ORDER BY c DESC;
```

## 11. Troubleshooting checklist

| Triệu chứng | Root cause | Fix |
|---|---|---|
| PHP `SQLSTATE[HY000] [2002]` | Aiven require SSL, PHP chưa bật | Verify `DB_SSL_CA` path + `mysqli_ssl_set` |
| Python `pymysql.err.OperationalError 1045` | User/pass sai hoặc chưa GRANT | Re-check user Aiven, `GRANT ALL` lại |
| Widget `Không kết nối được` | CORS / AI_SERVICE_URL sai | Verify PHP env `AI_SERVICE_URL` reach được ai-service |
| ai-service log `google.api_core... 429` | Vượt Gemini free tier 15 RPM | Đợi reset hoặc upgrade paid |
| `/knowledge/index` trả `indexed_count: 0` | Không có product trong DB | Import banh_store.sql xong reindex |
| Chroma mất data sau restart | Ephemeral disk | Add persistent disk (5.5 Option B) |
| Messenger `Callback URL Refused` | Chưa deploy hoặc path sai | Check Render logs, path `/channels/messenger/webhook` |
| PHP FK error khi migration | Chưa import banh_store.sql | Import gốc trước, migration sau |
| Render free tier cold start 30s | Sleep sau 15min idle | Upgrade Starter hoặc cron ping /health mỗi 10min |
